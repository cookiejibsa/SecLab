이 챕터의 범위

pwndbg 설치, 핵심 명령어, x64dbg와의 비교를 다룬다. heap 분석, ret2libc, ROP 체인 구성 등 심화 내용은 별도 pwndbg 심화 가이드에서 다룬다.

pwndbg가 GDB에 더하는 것

GDB는 강력하지만 기본 UI가 불편하다. pwndbg는 GDB 플러그인으로, 디버깅 중 레지스터/스택/코드를 자동으로 시각화해서 보여준다. IDA/x64dbg에 가까운 경험을 터미널에서 제공한다.

설치

# pwndbg 설치
git clone https://github.com/pwndbg/pwndbg
cd pwndbg
./setup.sh

# GDB 실행 확인
gdb --version
# pwndbg가 로드되면 시작 메시지에 pwndbg가 표시됨

기본 워크플로우

# 바이너리 실행
gdb ./target

# 또는 실행 중인 프로세스에 attach
gdb -p 1234

# 브레이크포인트 설정
b main          # 심볼로
b *0x401234     # 주소로
b *main+0x20    # 오프셋으로

# 실행
r               # run
r arg1 arg2     # 인자와 함께 실행
r < input.txt   # stdin 리다이렉션

pwndbg 핵심 명령어

명령어설명
context레지스터 + 스택 + 코드를 한 번에 출력
stack스택 상위 N개 항목 출력
heap힙 청크 목록 출력
vmmap메모리 맵 (각 영역의 권한 포함)
gotGOT 테이블 현재값
pltPLT 항목 목록
checksec바이너리 보안 기능 확인
cyclic 100100바이트 De Bruijn 패턴 생성 (오프셋 계산용)
cyclic -l 0x61616166패턴에서 오프셋 역산
search -x "90 90"메모리에서 바이트 패턴 검색

x64dbg vs pwndbg 비교

항목x64dbgpwndbg
OSWindows 전용Linux (주로)
UIGUI터미널 (TUI)
PLT/GOT 분석별도 플러그인내장 (got, plt)
힙 분석제한적glibc 힙 완전 지원
익스플로잇 개발불편pwntools와 연동 최적
스크립팅JavaScript 플러그인Python (GDB Python API)
