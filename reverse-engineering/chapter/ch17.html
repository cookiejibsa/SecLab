네트워크 프로토콜 리버싱

커스텀 프로토콜의 구조를 Wireshark + 정적 분석으로 역추적한다

접근 방법

악성코드 C2 통신이나 독점 클라이언트의 프로토콜을 분석할 때, 두 방향에서 동시에 접근한다. Wireshark로 트래픽을 수집해 패킷 구조를 추측하고, 동시에 바이너리의 send/recv 함수를 후킹해서 암호화 이전/이후 데이터를 확인한다.

Wireshark 기본 분석

# 대상 프로세스 트래픽 캡처 (Wireshark)
# 필터: ip.addr == C2_IP or tcp.port == 4444

# 커스텀 프로토콜 패킷 구조 추측
# 반복 등장하는 바이트 패턴 → 매직 바이트/헤더
# 고정 오프셋의 값 변화 → 시퀀스 번호, 길이 필드
# 페이로드 앞부분 고정 → 커맨드 ID

# Follow TCP Stream으로 전체 세션 확인

패킷 구조 역추적

/* 역추적한 커스텀 프로토콜 구조 예시 */
typedef struct {
    uint32_t magic;      // 0xDEADC0DE
    uint16_t cmd_id;     // 0x01=upload, 0x02=exec, 0x03=download
    uint16_t flags;      // 암호화 여부 등
    uint32_t payload_len;
    uint8_t  payload[];
} C2Packet;

send/recv 후킹으로 암호화 전 데이터 확인

// Frida: send() 직전 평문 덤프
Interceptor.attach(Module.findExportByName('ws2_32.dll', 'send'), {
    onEnter: function(args) {
        var socket = args[0];
        var buf    = args[1];
        var len    = args[2].toInt32();
        console.log('[send] len=' + len);
        console.log(hexdump(Memory.readByteArray(buf, len)));
    }
});

// recv() 직후 평문 덤프
Interceptor.attach(Module.findExportByName('ws2_32.dll', 'recv'), {
    onLeave: function(retval) {
        // this.args는 onEnter에서 저장해야 함
        console.log('[recv] received ' + retval + ' bytes');
    }
});
