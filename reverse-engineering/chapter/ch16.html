angr 심볼릭 실행

Python으로 바이너리를 수학적으로 푼다

심볼릭 실행이란

일반 실행이 구체적인 입력값으로 한 경로만 따라간다면, 심볼릭 실행은 입력을 "어떤 값이든 될 수 있는 변수"로 처리하고 가능한 모든 경로를 동시에 탐색한다. 결과적으로 "이 함수가 성공을 반환하려면 입력이 어떤 값이어야 하는가"를 수학적으로 풀 수 있다.

기본 패턴 — 크랙미 자동 풀기

import angr

# 바이너리 로드
proj = angr.Project('./crackme', auto_load_libs=False)

# 초기 상태: stdin에 심볼릭 입력 설정
state = proj.factory.entry_state(
    stdin=angr.SimFile(name='stdin', size=16)  # 16바이트 입력
)

# 탐색 목표 설정
simgr = proj.factory.simulation_manager(state)
simgr.explore(
    find=0x401234,    # 성공 경로 주소 (Ghidra에서 확인)
    avoid=0x401260   # 실패 경로 주소
)

# 결과 추출
if simgr.found:
    solution = simgr.found[0].posix.dumps(0)
    print(f'Input: {solution}')

find/avoid 주소 찾기

Ghidra에서 "Correct"/"Wrong" 문자열이 출력되는 분기 직전 주소를 찾는다.

/* Ghidra 디컴파일 */
if (check_serial(input) == 1) {
    puts("Correct!");   ← find: 이 puts의 주소
} else {
    puts("Wrong!");    ← avoid: 이 puts의 주소
}

한계와 대응

한계증상대응
경로 폭발 (Path Explosion)루프가 많으면 탐색이 기하급수적으로 늘어남veritesting 옵션, 루프 제한, 수동 BP 설정
시스템 콜 모델링복잡한 IO나 네트워크 코드에서 멈춤hook으로 대체 구현
부동소수점FPU 연산이 들어가면 정확도 저하concolic execution으로 보완
# 최적화 옵션
proj = angr.Project('./target', auto_load_libs=False)
state = proj.factory.entry_state()
state.options.add(angr.options.LAZY_SOLVES)   # 느린 SMT 해결 지연

# veritesting으로 루프 가속
simgr = proj.factory.simulation_manager(state, veritesting=True)

# 특정 함수를 stub으로 교체 (시스템 콜 우회)
@proj.hook(scanf_addr, length=5)
def scanf_hook(state):
    state.regs.eax = 1  # 성공 반환
