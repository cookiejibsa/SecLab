크랙미 분석 전략

크랙미(Crackme)는 RE 실습용으로 설계된 바이너리다. 보통 올바른 시리얼 키 입력, 숨겨진 기능 활성화, 플래그 추출 같은 목표를 가진다. 실전 악성코드 분석과 같은 접근법을 쓴다.

  • 1
    DIE로 아키텍처/패커 확인 → 패킹 여부 파악
  • 2
    pestudio/strings로 문자열 확인 → "wrong", "correct", "flag" 등 단서
  • 3
    Ghidra로 전체 구조 파악 → main 또는 검증 함수 위치
  • 4
    x64dbg로 동적 확인 → 분기 조건, 비교값 확인
  • 5
    패치 또는 키 역산

시나리오 1: 단순 문자열 비교

/* Ghidra 디컴파일 결과 */
int main() {
    char input[64];
    printf("Enter key: ");
    scanf("%s", input);
    if (strcmp(input, "s3cr3t_k3y") == 0) {

시나리오 2: 해시 비교

/* 더 일반적인 패턴: 입력을 해싱해서 비교 */
int main() {
    char input[64];
    int  hash;
    scanf("%s", input);
    hash = compute_hash(input);
    if (hash == 0xDEADBEEF) {  // 목표 해시값
        win();
    }
}

// 접근 1: x64dbg에서 compare 직전에 BP → 조건 패치 (jne → je)
// 접근 2: compute_hash 역산 → 0xDEADBEEF를 만드는 입력 찾기
// 접근 3: angr로 자동 역산 (Ch.16)

시나리오 3: 시리얼 키 검증

/* 자릿수별 검증 패턴 */
bool verify_serial(char* s) {
    if (strlen(s) != 16) return false;
    if (s[0] + s[1] != 0x9E) return false;
    if (s[3] ^ s[7] != 0x12) return false;
    // ... 각 조건을 모두 만족하는 키를 역산
}

// 접근: 각 조건을 방정식으로 보고 연립해서 풀기
// 또는 z3 solver (Python)로 자동화
# z3 solver로 시리얼 키 역산
from z3 import *

s = [BitVec(f's{i}', 8) for i in range(16)]
solver = Solver()

# 제약 조건 추가
solver.add(s[0] + s[1] == 0x9E)
solver.add(s[3] ^ s[7] == 0x12)
# 출력 가능한 ASCII 문자 제약
for c in s:
    solver.add(c >= 0x20, c <= 0x7E)

if solver.check() == sat:
    m = solver.model()
    result = ''.join(chr(m[c].as_long()) for c in s)
    print(f'Key: {result}')
