모바일 앱 리버싱

apktool/jadx로 APK 디컴파일, Frida로 런타임 분석

Android APK 정적 분석

# APK 언패킹
apktool d target.apk -o output/
# output/smali/     : Dalvik 바이트코드 (어셈블리 수준)
# output/res/       : 리소스 파일
# output/AndroidManifest.xml : 권한, 컴포넌트 선언

# Java 수준 디컴파일 (jadx가 더 읽기 쉬움)
jadx -d output/ target.apk
# output/sources/   : Java 의사코드

# AndroidManifest에서 먼저 확인할 것
# - uses-permission: 앱이 요청하는 권한
# - activity/service/receiver: 진입점 컴포넌트

분석 포인트

확인 항목방법
네트워크 통신 URL/IPjadx 코드 검색: "http", "https", "api"
암호화 키 하드코딩Base64 디코딩, 고정 문자열 검색
루트 탐지 코드"su", "RootBeer", "SafetyNet" 검색
SSL Pinning 코드OkHttp CertificatePinner, TrustManager 구현
Native 라이브러리.so 파일 → Ghidra로 분석

Frida로 런타임 분석

# Android 에뮬레이터에서 frida-server 실행
adb push frida-server /data/local/tmp/
adb shell chmod 755 /data/local/tmp/frida-server
adb shell /data/local/tmp/frida-server &

# Java 메서드 후킹
Java.perform(function() {
    var Activity = Java.use('android.app.Activity');
    
    // 특정 클래스의 메서드 후킹
    var CryptoHelper = Java.use('com.target.app.CryptoHelper');
    CryptoHelper.encrypt.implementation = function(data, key) {
        console.log('encrypt called:');
        console.log('  data: ' + data);
        console.log('  key:  ' + key);
        return this.encrypt(data, key);  // 원본 호출
    };
    
    // 루트 탐지 우회
    var RootDetector = Java.use('com.target.app.security.RootDetector');
    RootDetector.isRooted.implementation = function() {
        return false;
    };
});
💡
objection 활용

objection은 Frida 기반 명령줄 도구로, 스크립트 없이 SSL Pinning 비활성화, 루트 탐지 우회, 클래스 목록 확인 등을 대화형으로 할 수 있다. 빠른 초기 분석에 유용하다.
