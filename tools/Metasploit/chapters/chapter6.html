Chapter 06

정보 수집 & 스캔

공격 전 정찰의 중요성 — Nmap 통합, Auxiliary 스캐너, SMB/SSH/HTTP 열거까지 체계적인 정보 수집 방법론

🔍 왜 정찰이 가장 중요한 단계인가?

침투 테스트에서 실패하는 가장 흔한 이유는 성급함입니다. 대상 시스템을 충분히 파악하지 않고 익스플로잇부터 시도하면, 잘못된 버전의 모듈을 사용하거나 이미 패치된 취약점을 시도하는 낭비가 생깁니다. 더 나쁜 경우에는 불필요한 시스템 충돌을 일으킵니다.

좋은 침투 테스터는 공격 시간의 60~70%를 정찰에 씁니다. 대상을 완전히 이해한 뒤에는 나머지 작업이 훨씬 빠르고 정확해집니다.

🗄️ DB 조회 — 수집된 정보 한눈에 보기

메타스플로잇은 스캐너들이나 여러 모듈이 실행되고 나면 Metasploit DB에 결과가 쌓입니다. vulns는 스캐너가 발견한 취약점, creds는 획득한 계정 정보, loot는 시스템에서 꺼내온 파일, notes는 모듈이 자동으로 기록한 부가 정보입니다.

🔍 db 조회 실전 활용 
# ── hosts 조회 ──────────────────────────────────────
msf6 > hosts                               # 발견된 모든 호스트 목록
msf6 > hosts -c address,os_name            # 특정 컬럼만 출력
msf6 > hosts -c address,os_flavor,os_sp,purpose
msf6 > hosts -S 192.168.56.               # IP 패턴으로 검색
msf6 > hosts -o /tmp/hosts.csv             # CSV로 저장
msf6 > hosts -R                            # 결과를 RHOSTS에 자동 세팅
msf6 > hosts -d 192.168.56.5              # 특정 호스트 삭제

# ── services 조회 ───────────────────────────────────
msf6 > services                            # 발견된 모든 서비스 목록
msf6 > services -p 22                      # SSH 서비스만 필터
msf6 > services -p 80,443,22              # 여러 포트 필터
msf6 > services -p 1-1024                 # 포트 범위 필터
msf6 > services -s http,ftp,ssh           # 서비스 이름으로 필터
msf6 > services -u                         # 상태가 up인 것만
msf6 > services -c port,proto,name,info   # 컬럼 지정 출력
msf6 > services -S apache                 # 문자열 검색
msf6 > services -o /tmp/services.csv      # CSV로 저장
msf6 > services -R                         # 결과를 RHOSTS에 자동 세팅
🔨 db_nmap 실전 활용 
# ── vulns 조회 ──────────────────────────────────────
msf6 > vulns                               # 발견된 취약점 목록
msf6 > vulns -p 445                        # 특정 포트의 취약점만
msf6 > vulns -S ms17                       # 이름으로 검색 (ex. EternalBlue)
msf6 > vulns -h 192.168.56.5              # 특정 호스트의 취약점만

# ── creds / loot 조회 ───────────────────────────────
msf6 > creds                               # 수집된 자격증명 목록
msf6 > creds -h 192.168.56.5              # 특정 호스트 자격증명
msf6 > creds -p 22                         # 특정 포트 자격증명
msf6 > creds -s ssh                        # 서비스별 필터
msf6 > creds -t password                   # 타입 필터 (password, hash 등)
msf6 > loot                                # 수집된 파일/데이터 목록
msf6 > loot -t passwd                      # 타입으로 필터
msf6 > loot -h 192.168.56.5               # 특정 호스트 loot

# ── notes 조회 ──────────────────────────────────────
msf6 > notes                               # 수집된 노트 전체
msf6 > notes -h 192.168.56.5              # 특정 호스트 노트
msf6 > notes -t host.os.session           # 타입으로 필터
msf6 > notes -S smb                        # 문자열 검색

🔎 Auxiliary 스캐너 모듈

Metasploit의 Auxiliary 스캐너들은 특정 서비스에 특화된 정보를 추출합니다. Nmap이 "이 포트에 이런 서비스가 있다"고 알려준다면, Auxiliary 스캐너는 "이 서비스의 버전은 X이고, 설정은 Y이며, 이런 취약점이 있다"까지 파고듭니다.

🔨 SMB 열거 
# SMB 버전 및 OS 정보 감지
use auxiliary/scanner/smb/smb_version
set RHOSTS 192.168.56.101
run

# 공유 폴더 열거
use auxiliary/scanner/smb/smb_enumshares
set RHOSTS 192.168.56.101
run

# 사용자 계정 열거
use auxiliary/scanner/smb/smb_enumusers
set RHOSTS 192.168.56.101
run

# 익명 로그인 허용 여부
use auxiliary/scanner/smb/smb_login
set RHOSTS 192.168.56.101
set SMBUser guest
set SMBPass ""
run
🔨 SSH 열거 
# SSH 버전 감지
use auxiliary/scanner/ssh/ssh_version
set RHOSTS 192.168.56.101
run

# SSH 무차별 대입 (교육 목적, 본인 소유 시스템만)
use auxiliary/scanner/ssh/ssh_login
set RHOSTS 192.168.56.101
set USERNAME root
set PASS_FILE /usr/share/wordlists/rockyou.txt
set THREADS 10
run
🔨 HTTP 열거 
# 웹 서버 헤더 및 버전 감지
use auxiliary/scanner/http/http_version
set RHOSTS 192.168.56.101
run

# 디렉토리/파일 열거
use auxiliary/scanner/http/dir_scanner
set RHOSTS 192.168.56.101
set PATH /
run

# robots.txt 확인
use auxiliary/scanner/http/robots_txt
set RHOSTS 192.168.56.101
run
🔨 FTP 열거 
# FTP 버전
use auxiliary/scanner/ftp/ftp_version
set RHOSTS 192.168.56.101
run

# 익명 FTP 접근 허용 여부
use auxiliary/scanner/ftp/anonymous
set RHOSTS 192.168.56.101
run
