Chapter 02

설치 & 환경 구성

실습 환경을 처음부터 제대로 구축하는 방법 — Kali Linux 세팅, Metasploitable 타깃 구성, 그리고 격리된 랩 환경 설계

⚠️
인터넷 격리 필수

실습 환경은 반드시 인터넷과 격리된 가상 내부 네트워크에서 운영해야 합니다. Metasploitable 같은 의도적으로 취약한 VM을 인터넷에 노출시키면 실제 공격자에게 침투당할 수 있습니다.

🏗️ 실습 랩 아키텍처 설계

실습을 시작하기 전에, 전체 환경이 어떻게 구성될지 그림을 먼저 그려봅시다. 우리가 만들 랩은 세 가지 요소로 이루어집니다.

🗺️ 실습 랩 네트워크 다이어그램 
┌──────────────────────────────────────────────────────────────┐
│                Host Machine (여러분의 실제 컴퓨터)               │
│                                                              │
│  ┌──────────────────┐      ┌────────────────────────────┐    │
│  │   Kali Linux VM  │ <──> │     Target VMs (격리됨)     │    │
│  │    (공격자 머신)   │      │                            │    │
│  │                  │      │    Metasploitable 2/3      │    │
│  │    Metasploit    │      │    Windows Server 2008     │    │
│  │    Framework     │      │    DVWA (웹 취약점 랩)       │    │
│  │                  │      │                            │    │
│  │ IP: 192.168.56.x │      │     IP: 192.168.56.y       │    │
│  └──────────────────┘      └────────────────────────────┘    │
│                                                              │
│          ↑ Host-only Network (외부 인터넷 차단)                 │
│                                                              │
│        ⛔ 이 네트워크는 인터넷과 연결되지 않습니다                    │
└──────────────────────────────────────────────────────────────┘

핵심 원칙은 Host-only 네트워크 어댑터를 사용하는 것입니다. 이렇게 하면 VM들끼리는 통신하지만 인터넷으로는 트래픽이 나가지 않습니다. 마치 방 안에 별도의 미니 네트워크를 구성하는 것과 같습니다.

🐧 Kali Linux 설치 — 공격자 머신 구성

Kali Linux는 Offensive Security가 개발한 보안 특화 리눅스 배포판입니다. Metasploit, Nmap, Burp Suite, Wireshark 등 수백 개의 보안 도구가 미리 설치되어 있습니다. 개별 도구를 하나하나 설치하는 것보다 훨씬 빠르게 환경을 구성할 수 있습니다.

VMware Workstation Pro / Player에 Kali 설치

VMware는 성능이 더 좋고 네트워크 설정이 안정적입니다. Kali 공식 사이트에서 VMware 전용 이미지를 제공합니다.

✅ 권장 방법 — 사전 빌드 VM 이미지 사용 
# 1. https://www.kali.org/get-kali/#kali-virtual-machines 에서
#    VMware 64-bit 이미지 다운로드 (약 3GB)

# 2. 다운로드된 .7z 파일 압축 해제
#    7-Zip 또는 The Unarchiver 사용

# 3. VMware에서 Open → .vmx 파일 선택

# 4. 네트워크 어댑터 설정 변경
#    VM Settings → Network Adapter → Host-only

# 5. VM 시작, 기본 자격증명으로 로그인
Username: kali
Password: kali

# 6. 시스템 업데이트 (필수!)
sudo apt update && sudo apt full-upgrade -y

VirtualBox에 Kali 설치

VirtualBox는 무료이며 Windows, macOS, Linux 모두에서 동작합니다. VMware보다 약간 느리지만 학습 목적으로는 충분합니다.

✅ VirtualBox 방식 
# 1. Kali Linux VirtualBox 이미지 다운로드
#    https://www.kali.org/get-kali/#kali-virtual-machines
#    → VirtualBox 64-bit 선택

# 2. VirtualBox → File → Import Appliance → .ova 선택

# 3. 네트워크 설정
#    Settings → Network → Adapter 1
#    Attached to: Host-only Adapter
#    Name: vboxnet0 (없으면 File → Host Network Manager에서 생성)

# 4. 게스트 확장 설치 (클립보드 공유, 화면 조정 등)
sudo apt install -y virtualbox-guest-x11
sudo reboot

WSL2 (Windows Subsystem for Linux)

WSL2에서도 Metasploit을 실행할 수 있지만, 네트워크 격리 설정이 복잡하고 GUI 도구들이 제한적입니다. 빠르게 시작하고 싶은 분들에게 임시 방편으로는 괜찮지만, 본격 실습에는 VM을 권장합니다.

🔨 WSL2 + Kali 설치 
# Windows PowerShell (관리자 권한)에서
wsl --install -d kali-linux

# WSL2 Kali 셸에서 Metasploit 설치
sudo apt update
sudo apt install -y metasploit-framework

# 데이터베이스 초기화
sudo service postgresql start
sudo msfdb init

# msfconsole 실행
msfconsole
⚠️
WSL2 한계

WSL2는 Host-only 네트워크 격리가 어렵습니다. 반드시 실습 전용 VM 환경 구성을 강력히 권장합니다.

🎯 타깃 VM 구성 — Metasploitable

Metasploitable은 Rapid7이 제작한 의도적으로 취약한 Ubuntu 가상 머신입니다. 실제 악성 공격을 받지 않는 안전한 환경에서 Metasploit의 모든 기능을 연습할 수 있도록 설계되었습니다. 현재 버전 2와 3이 있습니다.

Metasploitable 2

  • Ubuntu 8.04 기반
  • 설정이 간단, 안정적
  • 고전적인 서비스 취약점 풍부
  • 초보자에게 강력 추천
  • VSFTPd, Samba, UnrealIRCd 등 취약 서비스 내장

Metasploitable 3

  • Ubuntu 14.04 + Windows 2008 R2
  • Vagrant + Packer로 직접 빌드
  • 더 복잡하고 현실적인 시나리오
  • 중급 이상 권장
  • 플래그 기반 CTF 구조
✅ Metasploitable 2 빠른 설치 
# SourceForge에서 다운로드
# https://sourceforge.net/projects/metasploitable/
# → Metasploitable2-Linux.zip 다운로드 (약 800MB)

# 압축 해제 후 .vmdk 파일 확인

# VirtualBox에서 새 VM 생성
# Type: Linux, Version: Ubuntu (64-bit)
# Hard disk: 기존 가상 하드 디스크 사용 → Metasploitable.vmdk 선택
# Network: Host-only Adapter

# 기본 자격증명
Username: msfadmin
Password: msfadmin

# IP 확인
ifconfig eth0
🚨
절대로 인터넷에 연결하지 마세요

Metasploitable은 수십 개의 심각한 취약점을 의도적으로 열어놓은 시스템입니다. 인터넷에 연결하는 순간 자동화된 봇들이 수 분 안에 침투할 것입니다. 항상 Host-only 네트워크를 사용하세요.

🗄️ Metasploit 데이터베이스 초기화

Metasploit은 스캔 결과, 발견된 호스트, 자격증명 등을 PostgreSQL 데이터베이스에 저장합니다. 데이터베이스가 연결되어 있어야 작업 내용이 세션 간에 유지됩니다. 이 설정을 빠뜨리면 매번 처음부터 다시 스캔해야 하는 불편함이 생깁니다.

✅ 데이터베이스 초기화 및 확인 
# PostgreSQL 서비스 시작
sudo systemctl start postgresql
sudo systemctl enable postgresql

# Metasploit 데이터베이스 초기화
sudo msfdb init

# 출력 예시:
[+] Starting database
[+] Creating database user 'msf'
[+] Creating databases 'msf'
[+] Creating databases 'msf_test'
[+] Creating configuration file '/usr/share/metasploit-framework/config/database.yml'
[+] Creating initial database schema

# msfconsole 실행 후 DB 상태 확인
msfconsole

msf6 > db_status
[*] Connected to msf. Connection type: postgresql.

# workspace 설정 (작업 분리용)
msf6 > workspace -a mylab
msf6 > workspace mylab

워크스페이스(Workspace)란?

워크스페이스는 서로 다른 작업을 구분하는 개념입니다. 고객사 A를 위한 침투 테스트와 고객사 B의 테스트 결과가 섞이지 않게 각각의 워크스페이스에서 작업할 수 있습니다. 마치 여러 개의 독립된 프로젝트 폴더처럼 생각하면 됩니다.

🔨 워크스페이스 관리 
# 워크스페이스 목록 보기
msf6 > workspace
* default
  mylab

# 새 워크스페이스 생성 및 전환
msf6 > workspace -a client_pentest_2025
msf6 > workspace client_pentest_2025

# 워크스페이스 삭제
msf6 > workspace -d old_workspace

# 현재 워크스페이스의 모든 데이터 초기화
msf6 > db_wipe

🔧 msfvenom 환경 확인 및 초기 테스트

설치가 제대로 되었는지 확인하는 가장 좋은 방법은 간단한 명령어를 실행해보는 것입니다.

🔨 설치 검증 명령어들 
# Metasploit 버전 확인
msfconsole --version
# 출력: Framework Version: 6.x.x

# msfvenom 버전 확인 (페이로드 생성 도구)
msfvenom --version

# 전체 익스플로잇 모듈 수 확인
msfconsole -q -x "show exploits; exit" 2>/dev/null | tail -5

# Kali에서 타깃(Metasploitable)에 ping 테스트
ping -c 3 192.168.56.101
# (Metasploitable의 IP를 ifconfig로 확인 후 입력)

# 타깃의 열린 포트 빠르게 확인
nmap -sV 192.168.56.101
💡
자동 시작 스크립트 만들기

매번 서비스를 시작하는 게 번거롭다면 ~/.bashrc에 alias를 추가해두면 편합니다. 아래 섹션에서 자세히 다룹니다.

➕ 편의성 개선 — .bashrc alias 추가 
# ~/.bashrc 또는 ~/.zshrc에 추가
alias msf-start='sudo systemctl start postgresql && sudo msfdb start && msfconsole'
alias msf-stop='sudo msfdb stop && sudo systemctl stop postgresql'

# 적용
source ~/.bashrc

# 이제 이 명령어 하나로 모든 것이 시작됩니다
msf-start

🌐 추가 실습 환경 — VulnHub & HackTheBox

Metasploitable만으로는 부족해질 때, 더 다양한 실습 환경이 필요해집니다. 두 가지 훌륭한 리소스를 소개합니다.

🌍 VulnHub

다양한 취약한 VM 이미지를 무료로 다운로드할 수 있는 사이트입니다. 난이도별로 수백 개의 머신이 있으며, 각 머신마다 CTF 스타일의 플래그가 있습니다. 완전히 오프라인에서 실습 가능합니다.

vulnhub.com

🖥️ HackTheBox

온라인 플랫폼으로, 실시간으로 업데이트되는 머신들에 VPN으로 연결해 침투 테스트를 연습합니다. 활발한 커뮤니티와 랭킹 시스템이 있어 동기부여가 됩니다. 무료 계정도 일부 머신 접근 가능.

hackthebox.eu
