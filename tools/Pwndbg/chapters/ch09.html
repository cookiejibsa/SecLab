Chapter 09 · Part 4 — 고급 활용

checksec & 보호 기법 분석

무엇이 막고 있는지 알아야 어떻게 우회할지 생각할 수 있다

checksec — 보호 기법 한 번에 확인

# pwndbg 내부에서
pwndbg> checksec

# 출력 예시
# Arch:     amd64-64-little
# RELRO:    Partial RELRO
# Stack:    No canary found
# NX:       NX enabled
# PIE:      No PIE (0x400000)
# RUNPATH:  b'/home/user/lib'

# 터미널에서 (실행 전에도 가능)
checksec --file=./vuln

각 보호 기법 — 원리와 우회

NX (Non-eXecutable) — Windows에서는 DEP(Data Execution Prevention)라고도 한다. 스택, 힙, 데이터 섹션에 실행 권한을 주지 않는다.

# 확인: NX enabled → 셸코드 직접 실행 불가
# 확인: NX disabled → 셸코드 실행 가능 (오래된 시스템)

# pwndbg에서 메모리 권한 확인
pwndbg> vmmap
# 스택 영역이 rw-p (실행 불가) → NX 적용
# 스택 영역이 rwxp (실행 가능) → NX 없음

# 우회: ROP (Return Oriented Programming)
# → 이미 실행 가능한 영역의 코드 조각(가젯)을 재사용
# → Chapter 07 참고

Stack Canary — 스택 프레임의 로컬 변수와 리턴 주소 사이에 랜덤한 값을 삽입한다. 함수 반환 시 값이 바뀌었으면 __stack_chk_fail()을 호출해 프로세스를 종료한다.

# 카나리 값 확인
pwndbg> p *(long*)($rbp - 8)
# $1 = 0x7ab3c9d2e1f40500  ← 하위 바이트는 항상 \x00 (null terminator 보호)

# 카나리는 TLS(Thread Local Storage)에 저장됨
pwndbg> p *(long*)($fs + 0x28)    # fs:0x28 = 카나리 마스터 값

# 우회 방법 1: 카나리 릭
# 포맷 스트링 취약점 등으로 스택 값 출력 → 카나리 읽기
# 페이로드에 읽은 카나리 포함해서 덮기

# 우회 방법 2: 브루트포스 (단, 포크 서버 환경에서만)
# fork()는 카나리를 그대로 상속 → 한 바이트씩 브루트포스 가능

PIE (Position Independent Executable) — 바이너리를 랜덤 주소에 로드한다. ASLR과 결합하면 바이너리, 스택, 힙, libc 모두 주소가 매번 달라진다.

# PIE 없음 → 바이너리 항상 같은 주소 (보통 0x400000)
# PIE 있음 → 매번 달라짐 (0x55555...

# pwndbg에서 현재 베이스 주소
pwndbg> vmmap ./vuln
# 0x555555554000  ← 현재 실행의 바이너리 베이스

# PIE 우회: PIE 베이스 릭
# 스택에 바이너리 주소가 있는 경우 (리턴 주소 등)
pwndbg> leakfind $rsp           # 스택에서 바이너리 주소 찾기

# 찾은 주소에서 베이스 계산
# 예: 스택에서 0x555555555129 (main+21) 릭
# main+21 = 바이너리 파일에서 오프셋 0x1129 (Ghidra에서 확인)
# pie_base = 릭된 주소 - 0x1129

# pwndbg의 $rebase로 오프셋 기반 주소 계산
pwndbg> p $rebase(0x1234)     # 현재 베이스 + 0x1234

RELRO (RELocation Read-Only) — GOT(Global Offset Table)를 읽기 전용으로 만든다. GOT 덮어쓰기 공격을 막는다.

# Partial RELRO: GOT 일부는 여전히 쓰기 가능 → GOT overwrite 가능
# Full RELRO: GOT 전체 읽기 전용 → GOT overwrite 불가

# GOT 확인
pwndbg> got
# puts@got    = 0x404018  [r-x] → Full RELRO
# puts@got    = 0x404018  [rwx] → Partial RELRO → 덮어쓰기 가능!

# Partial RELRO에서 GOT 덮어쓰기
# puts@got를 system() 주소로 덮으면
# puts("/bin/sh") → system("/bin/sh")

# 확인: 쓰기 가능한지
pwndbg> vmmap 0x404018       # GOT 주소의 권한 확인

ASLR 상태 확인 & 제어

# 시스템 ASLR 상태 확인
cat /proc/sys/kernel/randomize_va_space
# 0 = 꺼짐, 1 = 부분, 2 = 완전

# pwndbg에서 자동으로 끄는 설정
pwndbg> set disable-randomization on   # 기본값 (로컬 디버깅 편의)
pwndbg> set disable-randomization off  # ASLR 실제 동작 테스트

# 시스템 전체로 끄기 (root 필요)
echo 0 | sudo tee /proc/sys/kernel/randomize_va_space
